# Skills Catalog

## Directory Convention
- One skill = one folder.
- Each skill folder must contain a `SKILL.md`.
- Group skills by domain to support long-term expansion.

## Current Structure
- `ui/`: UI/UX related skills.
- `domain/`: domain/model/business skills (reserved).
- `data/`: dto/entity/storage skills (reserved).
- `platform/`: build/tooling/devops skills (reserved).
